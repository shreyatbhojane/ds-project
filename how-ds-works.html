How Data Structures Power TaskFlow

TaskFlow uses three core data structures to power instant undo history, FIFO task processing, and sequential storage without unnecessary framework overhead.

1. The Stack

LIFO: Last In, First Out

Every destructive action (e.g. deleting a task) pushes the complete task snapshot onto an Action Stack. Clicking "Undo (Stack)" pops the latest item off the top of the stack and restores it to your active list.

[ PUSH DELETED TASK ] [ POP TO UNDO ] +---------------------+ +---------------------+ | Action: "Read book" | <-- TOP | Action: "Read book" | --> Restored! +---------------------+ +---------------------+ | Action: "Pay bills" | | Action: "Pay bills" | <-- NEW TOP +---------------------+ +---------------------+ | Action: "Meeting" | | Action: "Meeting" | +---------------------+ +---------------------+ 
/* C Implementation in c/stack.c */
int stack_push(Stack* s, int val) {
    if (s->top >= s->capacity - 1) return STACK_ERR_OVERFLOW;
    s->items[++(s->top)] = val;
    return STACK_SUCCESS; /* O(1) Time Complexity */
}

int stack_pop(Stack* s, int* out_val) {
    if (s->top < 0) return STACK_ERR_UNDERFLOW;
    *out_val = s->items[(s->top)--];
    return STACK_SUCCESS; /* O(1) Time Complexity */
}

2. The Queue

FIFO: First In, First Out

Tasks arrive sequentially in your daily workflow. When you click "Process Next (Queue)", the oldest pending task at the FRONT pointer is marked completed first, maintaining natural FIFO fairness.

[ DEQUEUE / PROCESS ] [ ENQUEUE NEW TASK ] <-- FRONT [ Task #1 ] <-- [ Task #2 ] <-- [ Task #3 ] <-- REAR <-- [ New Task ] (Oldest, executes first) (Latest, waits in line) 
/* C Implementation in c/queue.c */
int queue_enqueue(Queue* q, int val) {
    if (q->size >= q->capacity) return QUEUE_ERR_OVERFLOW;
    q->rear = (q->rear + 1) % q->capacity;
    q->items[q->rear] = val;
    q->size++;
    return QUEUE_SUCCESS; /* O(1) Circular Buffer */
}

int queue_dequeue(Queue* q, int* out_val) {
    if (q->size == 0) return QUEUE_ERR_UNDERFLOW;
    *out_val = q->items[q->front];
    q->front = (q->front + 1) % q->capacity;
    q->size--;
    return QUEUE_SUCCESS; /* O(1) Time Complexity */
}

3. The Contiguous Array

Direct Indexing

Active tasks are indexed contiguously in memory. Direct index access allows the interactive UI to toggle, edit, or mark tasks as completed in instant O(1) constant time without scanning lists.

Index: [ 0 ] [ 1 ] [ 2 ] Value: "Buy Coffee" "Design Hero" "Team Sync" Address: 0x7FFE00 0x7FFE20 0x7FFE40 Pointer: tasks[0] tasks[1] tasks[2]
